# 海缸照顾（手机网页小应用）

这是一个给爸爸用的手机小应用。装好以后不联网也能打开；手机联网时，会自动换成最新内容。

## 一、发布到 GitHub Pages（你来做，一次就好）

1. 在 GitHub 新建一个**公开**仓库，比如 `reef-care`。
2. 把这个文件夹里的所有文件上传到仓库根目录，包括 `index.html`、`app.js`、`data.js`、`style.css`、`sw.js`、`manifest.json`、两个图标和 `img` 文件夹。
3. 打开仓库的 **Settings → Pages**，Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，然后保存。
4. 等一两分钟，网址就是 `https://你的用户名.github.io/reef-care/`。先用自己的手机打开试一下。

## 二、装到爸爸的手机上（请国内的朋友帮忙）

1. 用 Mate 80 自带的**华为浏览器**打开上面的网址。在**联网**状态下，把首页和几个指南都点开看一遍，等图片全部显示出来。
2. 点浏览器右下角的菜单，选 **“添加到桌面”**，桌面上就会出现一个“海缸照顾”图标。
3. 打开**飞行模式**，再从桌面图标打开，确认没有网络也能看。看完关掉飞行模式。
4. 第一次用“开始 10 分钟倒计时”时，如果浏览器问能不能播放声音或震动，选**允许**。倒计时期间请保持这个页面开着、屏幕不要锁，铃声才响得出来。

> GitHub 在国内有时打不开或很慢。只要第一次装好时能打开，以后就算打不开，也会用手机里存好的内容，照样能看，只是暂时收不到更新。

## 三、以后怎么更新内容

- **改文字或步骤**：只要改 `data.js`，上传覆盖到仓库。爸爸下次联网打开时，就会自动显示新内容。
- **加了或换了照片**：把照片放进 `img`，在 `data.js` 里引用它，再把照片文件名加到 `sw.js` 的 `CORE` 列表里，并把 `sw.js` 第一行的 `VERSION` 改一下（比如 `v1` 改成 `v2`）。这样新照片也会被存进手机，离线时也能看到。

## 四、`data.js` 里的照片标注怎么写

一条标注写成：`['文字', 标签中心x, 标签中心y, 箭头指向x, 箭头指向y]`

- 竖着拍的照片，坐标范围是 750×1000；横着拍的是 1000×750。左上角是 (0, 0)。
- 不要箭头时，只写前三项。

## 五、数据保存在哪里

每次记录的水温、盐度、换水日期，都只存在爸爸手机的浏览器里，不会上传到任何地方。

- 想看记录：让他打开应用里的“记录”页，截图发给你。
- 注意：如果清除了浏览器数据，这些记录会一起被清掉。
